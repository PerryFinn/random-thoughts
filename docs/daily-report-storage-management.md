# 日报内容管理、迁移与整体恢复

本切片实现 [#33](https://github.com/PerryFinn/random-thoughts/issues/33)，遵守父规格 #20 第 9–13 组和 ADR-0003。仅日报专用库允许版本／密文迁移及旧密钥兼容；既有模型监控、蓝牙数据与 Codex 原会话不迁移、不删除。

## 删除与竞争

内容管理分别统计全部时区的已保存日报、本窗口草稿和已确认快照；后两类仅在内存，窗口结束归零。单份删除始终确认，范围包含同报告日共存草稿；保留候选选择与可供下一次主动生成的快照。普通清空一次列出全部日期、时区及各类数量，无确认短语；保留设置和凭据。

窗口与测试共用 `DailyReportFlow.send` 的删除、清空、重置动作／状态。确认期间范围变化刷新确认，旧按钮无效。确认执行先取消受影响生成／扫描／确认并推进编辑代次，冻结提交，再等待已接收的存储队列；删除事务成功后才清内存。失败保留原正文、草稿及选择，已取消任务不恢复。清空成功清全部正文、草稿、候选、快照和选择。关闭、退出、时区变化沿用相同的代次隔离；不建永久删除账本。

## 版本与凭据

schema 1（正文／尺寸）、2（常规设置）、3（数据源）、4（AI 配置）按真实旧表结构逐级补齐必要字段；schema 5 将受支持旧凭据封装升级为格式 2。新增设置默认值仅由显式迁移写入。旧结构、全部必要字段及数据先校验，结构／密文／版本在一个事务提交，失败保留旧库并停止依赖操作。未知新版拒绝读写，不创建空库或静默替换坏字段。

格式 1 和格式 2 均使用 AES.GCM、随机 nonce 与格式／密钥版本认证；保留受支持旧密钥读取。封装重加密不改变逻辑凭据版本、校验基线和当前身份。未知格式／密钥或认证失败保留原封装，只阻断对应配置；其他配置和日报可用。恢复时重新检查配置基线，来源状态回到未检查，不自动请求网络或恢复草稿。

## 人工整体备份／恢复

1. 完全退出随想，并确认没有其他实例写入。只关闭日报窗口不算停机。
2. 整体复制 Application Support 下 `com.perryfinn.random-thoughts/DailyReports` 专属目录，包含 `reports.sqlite` 及仍存在的必要 SQLite journal；不要单独挑表或混搭不同时刻文件。
3. 恢复时同样完全退出，以完整副本整体替换该专属目录，再使用支持其 schema、密文格式和密钥版本的应用打开。不要在运行中替换、混搭主库和 journal，或手动删除正常恢复所需 journal。
4. 旧副本可能带回已删除日报、旧 Key 和旧设置；应用没有删除账本抵消人工恢复。无效数据源路径保留并提示；不会自动检查／扫描／生成。

应用不提供导入、自动备份或备份管理界面，也不隐藏旧库副本。复制操作不保证操作系统备份、剪贴板或 SSD 的残留清除。

## 损坏重置

故障页默认保留数据并提供打开专属数据文件夹；版本不支持时优先建议兼容应用。独立“重置日报功能数据”确认明确清除整个日报库、事务状态、所有日报设置、凭据和本功能内存，与普通清空分开。

存储独占锁覆盖打开、迁移、读写及重置，打开失败仍保留目录锁；不能抢占其他实例。确认重置后取消任务、等待旧写入、关闭连接，在同一锁内持久化无内容的 `reset-intent` 标记，再删除库及 SQLite 辅助文件。重置等待及执行期间，菜单再次打开日报或设置仅展示窗口，不另起旧库加载，不覆盖重置队列。标记仅含固定格式，不含正文、路径或凭据。只有旧存储清完、新库初始化完成才删除标记；部分失败明确提示数据可能已部分清除，后续打开只继续已确认的重置，不使用半库。未知标记拒绝处理。锁文件不作为占用证据，也不在持锁时删除。

## 验证边界

流程行为通过既定动作／状态接口验证；SQLite／CryptoKit 使用独立临时库与合成测试密钥。独占、迁移／提交失败、热 journal 恢复及重置中断使用专用测试子进程和完成屏障。仅运行纯构建及隔离 U/I/L，不启动应用、不触及用户库、不访问真实 Codex／AI。实际结果见 [testing.md](testing.md)。
