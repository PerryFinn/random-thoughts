# 扫描候选会话与确认会话快照

本切片实现 [#26](https://github.com/PerryFinn/random-thoughts/issues/26)，以 #25 本地提交 `f36669b` 为基线，遵守父规格 #20 第 2、3、12、13 组及 ADR-0001／0002。#25 在 GitHub 仍开放，原生阻塞关系仍存在；本次仅在本地继续实现，不改变 tracker 状态。

## 读取与完整性

界面和主要测试通过 `DailyReportFlow.send` 扫描、取消、选择和确认，读取同一状态面。扫描仅在日报窗口内运行，使用已保存的唯一来源身份；每次启动独立 stdio App Server，完成握手，分别完整分页当前与归档列表，再以 `thread/read(includeTurns: true)` 读取。每页显式传入 `modelProviders: []`，避免默认供应商筛选漏掉同一数据目录中的会话；显式列出稳定 `sourceKinds`，避免默认交互式筛选隐藏未知来源；内部来源仍始终排除。协议采用 #4 固定的 `openai/codex@66919805ea080053d1933b6b43afeb0d8bf70c91` v2 schema，检查完整 `itemsView`，不读私有文件。

按会话 ID 去重且当前优先。标题优先非空 `name`，后备 `preview`，仍为空显示“未命名会话”；工作目录标准化后分组，不折叠不同 worktree，缺目录进入“未归类”。完整目录仅在本机用于消歧，不进入遥测。

固定上游的稳定 `sourceKinds` 不能表达 `source={custom: ...}`：[来源过滤实现](https://github.com/openai/codex/blob/66919805ea080053d1933b6b43afeb0d8bf70c91/codex-rs/app-server/src/filters.rs#L53-L81) 仅将 `unknown` 匹配为明确的 Unknown。完整性指稳定读取接口支持的范围，不保证覆盖上游未列出的 custom 来源；不添加虚构参数或私有读取绕过。空供应商列表的必要性见 [列表默认筛选](https://github.com/openai/codex/blob/66919805ea080053d1933b6b43afeb0d8bf70c91/codex-rs/app-server/src/request_processors/thread_processor.rs#L4611-L4621)，正常用户分类见 [ThreadSource](https://github.com/openai/codex/blob/66919805ea080053d1933b6b43afeb0d8bf70c91/codex-rs/protocol/src/protocol.rs#L2583-L2599)。

两份列表完整且无候选为完整空扫描。具体读取失败列出会话及固定错误；只有至少一份候选成功且完整知道两份列表范围，才可确认部分会话扫描的成功项。列表失败、必要方法／参数／schema 不兼容、所有潜在候选不可读均失败，不可确认，也不称“降级成功”。扫描结果和数据源当前可用状态分别表达。启动扫描先取消同来源的旧基础检查，旧检查回调不能覆盖扫描结果；锁等待失败仅报告扫描错误，保留来源已有的可用／未检查状态。

扫描持有以来源身份为键的跨进程 `flock`，空锁文件位于当前用户临时目录，不写 Codex 数据目录。排队可取消，30 秒截止，不抢锁或终止持锁进程。每笔协议读取有 30 秒截止；仅意外退出、传输中断或超时允许整次最多一次透明重启，重新完整扫描。路径、权限、方法、参数、schema 和锁失败不重试。

## 正文与报告日

工作轮次按可靠 `startedAt` 和报告时区的半开日区间整体归日，不假定一天 24 小时；缺开始时间的轮次排除且不展示。用户仅拼接顺序 `text`，助手仅取非空 `final_answer`；元数据、图片／音频、reasoning、工具／命令、日志及未知阶段不作为正文。没有最终回复的用户正文保留，标记结果未确认。

候选至少有一轮当天非空用户正文。选中会话纳入全部当天合规轮次；首轮当天之前的全部合规轮次作为背景，保留其原日期和实际报告时区。未来内容不纳入。子代理、自动化和记忆整理始终排除；`cli`／`vscode`／`appServer` 且 `threadSource` 为空或 `user` 的用户来源默认全选，未知来源默认不选。未知来源即使自报 `threadSource=user` 也不自动获得信任。全选和分组选择遇到未知来源也先提示风险，明确纳入仅适用于当前报告日与本次选择，不形成长期信任。

## 选择、快照与生命周期

右侧抽屉是可关闭的非模态区域，提供全选／全不选、分组／逐会话、刷新、取消和确认。确认固定不可变的内存快照并关闭抽屉。固定前尽力遮盖高置信凭据、鉴权值及私钥；失败保留可用内容并持续显示非阻断提示，始终说明快照仍属敏感工作数据。查看／确认不重读 Codex，不展示正文预览或原会话跳转。

刷新与重选保留原快照，并提示需重新确认；已确认快照和只读实际生成来源是独立状态，#26 不伪造尚未实现的生成来源。不同报告日分别保留确认快照，未知来源授权不跨日或跨扫描沿用。保存新来源取消旧扫描、清未确认候选与选择，保留快照、草稿和日报。回调须匹配扫描代次、来源代次及窗口生命周期。实际关闭／退出释放全部扫描材料，返回编辑／隐藏／最小化保留。有效时区变化按受影响时区清理并重新扫描，不恢复已结束的材料。

快照、正文、来源及选择不进数据库、UserDefaults、恢复文件或日志。扫描遥测仅包含完整／部分／失败／取消与聚合候选／成功／失败数量；不携带报告日、来源身份或其哈希、标题、路径、原始 Error／stdio。

## 验证

沿用已确认的流程动作／状态、真实 stdio wire、独立目录和无窗口布局边界。覆盖分页去重、DST／午夜、来源／内容过滤、完整／部分／失败、不可变确认、脱敏失败、旧回调、锁排队与取消、一次重启及隐私出口。纯构建和隔离测试的实际记录见 [testing.md](testing.md)；真实 Codex／AI、应用启动与系统交互由获授权的 #35 验收承接。
