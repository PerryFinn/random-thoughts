# 配置与检查唯一 Codex 数据源

本切片实现 [#25](https://github.com/PerryFinn/random-thoughts/issues/25)，遵守父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20) 第 3、11、12、13 组、正式决议 #15 和 ADR-0001／0002／0003。依赖 #23 已有本地提交 `27b065e`，GitHub 仍开放；本票不改变其远端状态。会话扫描由 #26 接入，真实读取闭环由 #35 验收。

## 保存、发现与身份

设置与主要测试共用 `DailyReportFlow.send` 的编辑、撤销、保存并检查、主动重新发现与取消检查动作。来源身份同时绑定稳定可执行入口和规范化、解析符号链接后的单个数据目录。自动模式持久化所选入口，不变成手动模式，不因入口失效或重启重新发现。

首次自动选择及主动重新发现按 `~/.local/bin/codex`、启动继承 PATH 中的绝对目录、`/opt/homebrew/bin/codex`、`/usr/local/bin/codex` 顺序检查。跳过相对 PATH、应用包内私有入口及不可执行文件，选首个通过基础文件检查的入口，不比较版本。入口保留安装器提供的稳定路径，不跟随符号链接固定到版本文件。用户可手选入口或目录。

目录优先级为显式选择、启动继承 `CODEX_HOME`、`~/.codex`。显式或继承值无效时保持选择并给出修复方向，不创建 Codex 目录、不回退、不聚合。已解析目录随来源保存；只有主动保存或重新发现才重新解析运行环境。

保存选择先完成同库事务，再执行检查；路径或协议检查失败仍保留新选择，存储失败保留完整旧选择及编辑输入。新来源成功提交时取消旧检查、递增来源代次，通知运行环境终止旧扫描、释放未确认候选与选择。检查及诊断回调必须匹配代次；既有快照、草稿、已保存日报和使用固定快照的生成保持原状。

## 操作级 stdio 检查

每次检查启动所选用户入口的 `app-server`，传入选定目录，完成 `initialize`／`initialized`，禁用实验能力。随后以稳定 `thread/list` 分别探测当前与归档列表；有会话时对首个会话执行 `thread/read(includeTurns: true)`，验证必要会话、工作轮次和已知文本类型的 schema。空列表可用，具体读取契约在实际出现会话时验证，不制造会话。基础检查不分页扫描、不建立候选或快照。协议依据 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 和 #4 固定的 `openai/codex@6691980` schema。

方法、参数与必要字段不兼容分别返回固定错误；未知内容类型仅忽略，不猜测为正文。按新增片段寻找换行，单条协议响应最多缓冲 64 MiB，超过该资源边界返回固定读取失败，不截断正文或误报 schema 不兼容。检查有 30 秒操作截止时间；结束、取消或超时关闭管道并回收自己的子进程。没有常驻进程、共享 socket、JSONL fallback、自动重试、安装、下载或更新。

当前状态仅为未检查／可用／不可用，检查中独立表达。启动恢复配置时一律未检查，不自动启动子进程。有限历史只保留当前身份对应的最近成功 UTC 时间及解析后的数字版本，历史成功不能代表当前可用。取消不写成成功；不可用仍可手写、编辑与查看日报。

## 持久化、界面与隐私

schema 3 增加单行来源设置，配置、解析身份和有限诊断都进入既有 SQLite 库；不存当前状态、列表、轮次、stdout／stderr 或原始 Error。本仓库不做兼容或迁移：旧 schema 拒绝读写并保留原库，不自动删除、重建或重置。

界面分别显示当前状态、检查活动、已保存入口／目录、历史成功时间和数字版本。入口、目录错误统一按固定分类显示在对应字段，与协议诊断区互斥，给出手选、重新发现或更新用户安装的 Codex 等修复方向；长内容滚动，保存并检查／撤销固定底部，启用的具体控件使用手形。离开编辑页或关闭设置统一保护未保存输入；实际关闭或退出取消检查，返回编辑不取消。

入口和目录只在本机设置显示，不进入日志或可复制诊断。stderr 直接丢弃，stdout 只用于当次内存解析。遥测仅接受固定结果、固定错误枚举和受限数字版本，不接收路径、入口、源 ID、原始响应或 Error。

## 验证边界

沿用 #20 已确认的流程动作／状态、真实 SQLite、真实 stdio 协议替身和无窗口布局边界。隔离沙盒仅新增专用合成 App Server 替身执行许可；发现目录全部注入独立临时位置。替身严格核对握手、方法和参数，注入路径／权限／协议错误、通知、截断传输、取消及迟到结果。不启动应用、不访问真实 Codex／AI。实际命令与结果记入 [testing.md](testing.md)。
