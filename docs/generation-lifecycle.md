# 生成中的变化、取消与服务错误

本切片承接 [#32](https://github.com/PerryFinn/random-thoughts/issues/32) 和父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20)，基于本地 `4db3414` 的直接／有限分批实现。2026-10-20 只读核对远端 main 仍为 `123948d`，#32 的原生阻塞项 #31 仍开放；本地前置实现不改变远端阻塞状态。

## 固定输入与配置

界面与主要业务测试继续共用 `DailyReportFlow.send`。生成固定已确认会话快照、实际已保存历史、常规设置和当前已校验服务。端点、模型、服务默认值、凭据替换／删除及当前服务切换成功提交后取消本次，包括未派发的提取、归并和成文；提交失败保留旧配置及任务。仅修改 O 是请求字段的窄例外：当前整次剩余阶段继续用旧 O，新生成必须重新校验。C／并发／语言／偏好／回看仅影响下一次。

替换或规模确认到启动之间，配置、来源、设置或实际历史变化须重新规划并确认；旧按钮不能授权新输入。旧基线的成功或失败均不能覆盖新基线资格。当前身份与资格分开，失败不自动切服务或模型。

## 错误与等待

仅按明确协议错误代码、参数或有限的原生字段拒绝证据归类。403／404 不能单独证明鉴权或模型错误，429 不能单独证明配额不足，解析失败不能证明请求配置失效。原生错误仅提及字段名而没有明确拒绝证据时仍属未知；不把服务原文、原始 Error 或 stdio 带到 UI、日志、Markdown 或数据库。

明确鉴权／模型／必要参数不兼容使匹配基线失败。网络、临时、限流、配额、上下文、单次解析错误保留资格；重定向不跟随，引导修正最终端点。必要控制被拒绝不删字段重发。正文区持续说明固定错误类别、原内容保留和下一步。

明确限流且有可靠 `Retry-After` 时显示等待时间，HTTP 错误、HTTP 200 非流式原生错误对象和流内错误遵守相同规则；不可靠或缺失时不编造。等待结束只开放手动从头重试，不派发请求。额度不足只在明确配额证据下说明。

## 取消、超时与结束

取消立即恢复本地编辑，不另确认；取消本地传输和整次任务，隔离迟到的成功、失败、进度与资格回调。任一必要请求失败，停止派发并取消其他在途请求；在本地计数、辅助选择或进度回调期间取消，也不能继续发送下一阶段。旧正文与整份草稿生成来源一起保留，不产生部分日报、恢复文件或来源档案。服务方处理或计费不保证撤回。

每请求分别执行连接 30 秒、非流式完整结果 300 秒、流式连续无有效进展 90 秒的期限。心跳不算有效进展，整次分批没有统一短时限。睡眠不主动取消或请求；唤醒按实际经过时间判断，超时结果不能接受。网络恢复、唤醒、重新开窗和等待结束都不自动发送。

手动重试使用最新有效保存配置、语言／偏好／回看及实际历史，使用当前已确认快照，从头规划；不自动重读 Codex。缺资格先显式校验，校验结束不自动生成。手写或已编辑草稿仍须替换确认。

关闭／退出把正在生成与全部日期／时区草稿合并保护，默认返回编辑。打开面板不取消；生成结束或正文变化刷新面板并使旧确认失效。只有实际确认结束才取消。切换 Codex 数据源只取消扫描，保留固定快照生成；有效时区变化及内容删除按受影响范围取消，具体删除／存储能力见 [#33](daily-report-storage-management.md)。

沿用父规格已确认的流程动作／状态及真实协议传输入口，使用受控时钟、调度屏障、迟到回调和合成错误，验证直接及多层并发竞争，不用任意 sleep、真实限流、真实 Codex 或 AI。实际命令、结果与未执行项见 [testing.md](testing.md)。隔离验证不代表实际睡眠唤醒、原生窗口或父规格整体验收完成。
