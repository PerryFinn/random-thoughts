# Triage 标签

各技能使用五个规范化的 triage 角色。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本 tracker 中的标签 | 含义 |
| -------------------------- | ------------------ | ---- |
| `needs-triage`             | `needs-triage`     | 等待维护者评估此 issue |
| `needs-info`               | `needs-info`       | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现 |
| `wontfix`                  | `wontfix`          | 不会处理 |

当技能提到某个角色时，使用表格中对应的标签字符串。

如果本仓库实际使用的标签词汇发生变化，请编辑右侧一列。
