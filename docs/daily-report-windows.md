# 日报窗口与应用生命周期

本切片实现 [#22](https://github.com/PerryFinn/random-thoughts/issues/22)，遵守父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20) 的第 1、12、13 组决策。

## 动作、状态与系统边界

`DailyReportFlow` 是原生界面与隔离测试共用的动作／状态入口。#22 提供窗口存在性、启动原因、单日期导航和历史折叠状态；#23 接入手写、保存、历史、数据库、全部草稿关闭保护和正常尺寸，详见 [daily-report-content.md](daily-report-content.md)。扫描与生成由后续票接入。

窗口存在性决定模式：日报或设置至少一个存在时为前台窗口模式；两者真正关闭后为菜单栏模式。隐藏、最小化、睡眠和唤醒不删除窗口，也不停止模型刷新或蓝牙。重复打开使用现有窗口，反最小化并聚焦；关闭回调只接受当前窗口实例，旧实例不能关闭新实例。

`AppWindowCoordinator` 是 AppKit 系统边界及 `setActivationPolicy` 唯一写入者。它持有各窗口的控制器，以窗口实例确认真正关闭，并执行流程发出的窗口动作。SwiftUI 内容不查找窗口标题或延时猜测窗口是否已经创建。主动启动与 Finder／Spotlight 再次打开进入日报；登录启动只保留菜单栏。普通窗口激活不被误当再次打开，打开设置不会额外打开日报。

应用声明 `LSUIElement`，从菜单栏身份开始启动；协调模块只在日报或设置存在时切到前台窗口模式，避免登录启动先显示 Dock。启动原因由公开的打开应用 Apple Event 中的登录项标记识别，不读取 Codex 或用户文件。

原生窗口使用 AppKit 的同步窗口创建、关闭委托和菜单响应链，内容仍由 SwiftUI 构建。这一边界使启动原因、真实窗口存在性和聚焦顺序由一个模块管理，避免分散在异步场景回调中。

## 界面范围

| 窗口 | 原生内容尺寸与行为 |
| --- | --- |
| 日报 | 默认 1100×760pt、最小 900×620pt；标准标题栏，可调整、最小化、缩放、全屏。默认展开历史／正文双栏，支持单日期前后导航、日期选择和历史折叠。 |
| 设置 | 固定 860×620pt；可关闭，禁最小化、缩放、全屏，每次打开在活动显示器居中。保留模型监控与蓝牙入口，工作日报入口包含常规、数据源、AI 服务、内容管理四组。 |

菜单栏保留模型与蓝牙状态、锁屏、设置和退出，增加日报入口。应用菜单提供 ⌘1、⌘,、⌘W、日报 ⌘M、⌘Q，不提供新窗口或 ⌘N。

#22 提供日报窗口骨架与设置分组入口；#23 将正文区域替换为手写／安全预览和保存闭环；#24 接入[常规设置及离开保护](daily-report-settings.md)。扫描、生成、删除及其他设置仍由后续票接入。授权的聚焦、快捷键、Dock 和系统交互验收由 #35 承接。

## 日报遥测

CocoaLumberjack 固定为 3.10.0，生产只向独立 `DDLog` 注册 `DDOSLogger`，subsystem 为 `com.perryfinn.random-thoughts`，category 为 `DailyReports`。本票类型化入口只允许 `window_mode_changed` 和前台窗口／菜单栏模式枚举；不接受自由文本、错误、路径、来源、正文或凭据。日志对象的 file/function 使用固定标记，line/context 为 0，tag 为 nil，不注册 formatter、文件或网络 logger。既有模型与蓝牙日志不迁移。

隔离测试使用独立 `DDLog` 与线程安全内存 logger，提交全部事件后在日志队列外调用 `flushLog()`，检查完整日志对象和最终字符串。该屏障只保证已提交事件处理完成，不证明系统 OSLog 已落盘。

## 验证边界

测试边界采用 #22 与父规格已经确认的流程动作／状态接口、不创建窗口的 `NSHostingView` 尺寸测量、真实日志框架的内存捕获。所有系统窗口动作以受控边界替代，不调用真实聚焦，不启动应用，不访问真实 Codex／AI。实际命令和结果记录于 [testing.md](testing.md)。
