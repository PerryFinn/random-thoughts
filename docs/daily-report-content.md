# 手写、保存与日报历史

本切片实现 [#23](https://github.com/PerryFinn/random-thoughts/issues/23)，沿用父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20) 第 1、2、9、11、12 组及 ADR-0002／0003。会话扫描、AI、设置编辑、删除、迁移与重置由其他票承接。

## 流程接口与内存状态

窗口和主要测试都通过 `DailyReportFlow.send` 提交日期、正文、预览、复制、保存、确认、放弃与关闭动作。持久化以异步存储边界注入，时钟、剪贴板和窗口动作由运行环境提供。数据库不可用或被另一实例占用时停止编辑，不创建可写草稿；保存失败仍允许编辑、复制和主动本地重试。

报告日使用公历日期和实际 IANA 时区作为键；边界为当地日开始到下一日开始的半开区间，即使夏令时跳过午夜也重新取下一日开始，日期导航不加固定 86,400 秒。历史包含已保存及本窗口有草稿的日期，明确显示时区及草稿文字状态。

每个键最多一份已保存正文及一份内存草稿。首次正文变化才创建草稿，手写后删空仍保留草稿；编辑既有日报精确回到基线后清除草稿。空格、换行与 Unicode 参与精确比较。切日、隐藏、最小化保留全部草稿；再次真正打开回到今天，草稿不恢复。手写和已保存编辑没有生成来源。

## 保存与确认

首次保存直接提交；覆盖保存先显示附着日报窗口的可调整原始 Markdown unified diff，红删绿增，未变行可折叠。相同正文显示无变化但仍允许明确保存。确认标识绑定报告日、实际正文与草稿状态；正文、目标或关闭保护范围改变后刷新确认，旧按钮无效。

原始 Markdown 逐字保存与复制，不重套六章节，不脱敏、不附来源。保存时间每次成功提交均更新；只有最终存在有效用户修改时更新最后编辑时间，否则沿用旧值。失败保留原日报及草稿，成功才清该日期草稿；提交期间冻结正文修改与结束动作，避免未完成写入越过关闭边界。

放弃草稿始终确认。关闭日报和退出检查全部日期／时区草稿，列出范围，默认返回编辑；需要保留先逐份明确保存，不自动或批量保存。设置关闭不丢日报草稿。面板期间范围变化必须重新确认，真正结束才释放内存并清除确认面板，旧确认不能带入新窗口。

预览使用本机原生文本 Markdown 解析与 SwiftUI 文本渲染，保留标题、段落和列表的分隔与列表标记，没有 WebView、HTML／脚本执行或远程图片加载；仅允许用户主动点击 HTTP(S) 或邮件链接。编辑器、确认 diff 和底部操作在最小尺寸及长正文下仍可滚动访问。

## 单库边界

生产目录通过 Foundation 解析当前用户 Application Support，位于 `com.perryfinn.random-thoughts/DailyReports/reports.sqlite`。目录 0700、数据库与锁文件 0600；不迁移既有模型或蓝牙数据。同目录的进程锁覆盖打开与所有读写，锁文件的存在不代表占用；进程结束释放锁，不抢占另一实例。

首个 schema 使用显式版本和真实 SQLite 事务，设置 `journal_mode=DELETE`、`synchronous=EXTRA`、`secure_delete=ON`。仅保存报告日、原始 Markdown、UTC 保存时间、可空最后编辑时间，以及正常窗口内容宽高。没有草稿、基线、来源、恢复副本或生成档案。SQLite 管理正常 rollback journal。

只有明确不存在主库且没有待恢复事务或重置意图时才初始化。打开、权限、字段、schema 或版本错误保留原数据并停止操作，不静默创建空库；schema 校验包含必填列和报告日复合主键，读取时拒绝重复报告日。本轮不实现升级、迁移、删除或重置，#33 承接完整验收。错误向界面和遥测只提供固定类别，不输出正文、路径或 SQLite 原始错误。

正常尺寸进入同一数据库；只记录非最小化、非全屏的内容尺寸，以最新收到的尺寸去重并按顺序写入，快速调回先前尺寸也保留最终值。退出等待已收到的尺寸队列完成；等待期间出现新草稿时仍须确认，不提前终止进程。返回编辑或取消现有确认时，等待中的退出也随之取消，旧任务完成后不能重新触发退出；确认已结束后的迟到取消回调无效。重新打开时限制到主显示器可见区域并居中，不保存位置或其他恢复状态。小于最小窗口的显示区域优先保证窗口可见。

## 验证边界

已确认测试边界是流程动作／状态、真实 SQLite 存储和无窗口 `NSHostingView` 布局。所有数据纯合成，目录独立；存储故障使用受控边界或专用测试子进程，不触及用户数据库。锁验证仅使用专用测试子进程。实际命令、结果和未执行项记录于 [testing.md](testing.md)。
