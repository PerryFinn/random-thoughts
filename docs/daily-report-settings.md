# 报告时区与常规生成设置

本切片实现 [#24](https://github.com/PerryFinn/random-thoughts/issues/24)，遵守父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20) 第 2、7、10、12 组、设置决议 #13 及 ADR-0002／0003。常规设置由本票开放；数据源由 [#25](codex-data-source.md) 接入，AI 服务配置与凭据由 [#27](ai-service-settings.md) 接入，内容管理由 [#33](daily-report-storage-management.md) 接入。

## 统一流程与编辑

界面与主要测试继续通过 `DailyReportFlow.send` 操作。常规设置区分已保存值、编辑输入和实际生效报告时区：跟随 Mac 或固定有效 IANA 时区、中文／英文、自然语言生成偏好、历史回看 0–7 个日历日（默认 1），统一保存或撤销。固定时区可搜索、选择，包含 [IANA 正式定义](https://data.iana.org/time-zones/tzdb/etcetera) 的 `Etc/GMT-14` 至 `Etc/GMT-1`、`Etc/GMT+1` 至 `Etc/GMT+12`，以及 [IANA 无斜杠标识](https://data.iana.org/time-zones/tzdb/backward)，如 `CET`、`CST6CDT`。合法性按 IANA 标识与本机解析校验，不把搜索候选当作穷尽集合，也不接受 Foundation 额外支持的 `GMT+0800` 等非 IANA 名；搜索只列本机可解析项。无效输入的错误就地显示，保存不联网。生成偏好不能改变语言、事实边界或六章节模板。

设置窗口可独立加载同一日报数据库，不需要先打开日报。所有设置进入同一 SQLite 事务；提交期间冻结用户编辑、保存和结束动作。失败保留旧生效设置、旧草稿及编辑输入，并停留编辑页；成功才更新生效值。输出语言、偏好和回看保存后只影响下一次生成，运行中已取得的值副本不改变。本票不为生成另读历史正文、不展示或额外持久化历史正文副本，实际历史输入规划由 #29 承接。

日报工具栏只读显示生效时区；已保存日报和其他时区草稿的日期／时区身份不重新归日、合并或改名。设置与报告日读取共用 `ReportTimeZone` 的 IANA 校验，所选有效时区能原样保存并重新打开，不能在日报读取时被另一套候选范围拒绝。查看历史记录时，其自身时区仍用于日期导航。已保存固定时区失效时保留原字符串、显示修复提示，阻止相关扫描／生成；不改用 Mac 时区。已有日报仍可查看、编辑。

## 时区与草稿

手动保存前展示实际时区变化及旧时区全部草稿日期、数量、保留范围。只有有效时区改变且旧时区有草稿时才要求删除确认，默认取消。仅改变模式、实际时区不变时不删草稿。确认绑定编辑值、时区及草稿范围，面板期间变化必须刷新并重新确认，旧按钮不能提交新范围。

确认后先冻结用户动作，全部设置事务成功才清除已确认旧时区的所有日期草稿并切换；保留目标时区草稿、其他时区草稿和全部已保存日报。取消或事务失败不执行手动删除、切换或重扫。

跟随 Mac 的实际 IANA 时区自动变化直接取消旧时区受影响任务、清除其全部内存草稿、切换并发出重扫，事后说明数量，不事前确认。固定模式不随系统变化切换；若编辑正在改为跟随 Mac，系统变化会刷新尚未提交的影响范围。系统通知与唤醒共用同一个流程动作，重复通知不重复清除或重扫。

正文或设置提交期间，系统时区通知合并为最新值，待事务成功或失败返回后再串行应用自动变化；提交完成前不清除草稿或切换，避免先删除后被迟到保存恢复。已完成的显式正文保存属于已保存日报，自动变化保留它；提交失败时未保存的旧时区草稿仍按自动变化规则清除，设置编辑输入保留。手动设置切换与后续自动切换各自使用实际生效值，确认没有授权删除的目标时区草稿不能被手动提交误删。

有效时区变化使正文编辑代次失效，旧日期／窗口／代次的回调不能恢复被清除草稿。取消和重扫通过类型化的运行环境 Adapter 发出，携带旧时区、新报告日及代次，不写日志；#24 的生产组合尚无数据源或生成任务，隔离测试捕获这一接口，后续票接入真实能力。语言、偏好、回看变化不发取消或重扫。

## 离开与关闭

常规有未保存编辑时，切设置分组、切侧栏或关闭设置统一提供取消、放弃设置编辑、保存并继续；时区删除影响合并到同一面板，不叠加第二次确认。取消不提交，放弃只撤销设置输入，不删日报草稿；保存失败留在原页。确认保留目标页面／窗口身份，过期窗口回调不能关闭新窗口。

退出同时存在未保存常规编辑和日报草稿时，也在一个面板列明全部范围；保存设置后退出或放弃设置后退出都明确说明将放弃未保存日报草稿，默认返回编辑。设置事务未完成时不允许退出，退出继续等待正常窗口尺寸写入。

## 持久化与验证边界

当前 schema 为 5，常规设置表保存模式、固定 IANA 原值、语言、偏好、回看天数；#25 增加来源配置及有限历史诊断表，[#27](ai-service-settings.md) 增加三协议配置、加密凭据和独立当前选择，#33 接入事务迁移与格式 2 凭据封装。新库显式初始化默认值；已有表／行／字段缺失或无效不静默补默认。已保存固定时区失效属于设置修复状态，保留值而不当作空库。

[#33](daily-report-storage-management.md) 接入日报专用库受支持旧格式的事务迁移；未知新版拒绝读写并保留原数据，不自动重建或未经确认重置。既有模型／蓝牙数据不迁移。目录独占、权限、事务和禁止内容副本继续沿用 #23。设置保存失败后可主动本地重试。

已确认测试边界仍为流程动作／状态、真实 SQLite 事务和无窗口 `NSHostingView` 布局。使用合成数据、独立目录、受控时区与取消／重扫接收器；不启动应用，不访问真实 Codex／AI。实际命令、结果及未执行项记录于 [testing.md](testing.md)。
