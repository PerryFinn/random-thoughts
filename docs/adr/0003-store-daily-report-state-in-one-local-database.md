# 用单一本地数据库保存日报内容与设置

工作日报和日报设置保存在当前用户 Application Support 专属目录中的一个 SQLite 数据库，以事务保证明确保存、配置修改和删除的完整提交。API Key 加密存入同一数据库，加密密钥随应用打包，不使用 Keychain；配置字段、凭据密文、凭据版本和校验状态可以在同一事务提交，失败保留完整旧配置。

用户选择无需 Keychain 或解锁口令的使用方式，并接受其保护范围仅为避免数据库中的 API Key 明文直接可见；获得应用和数据库后仍可以解密。凭据不绑定当前 Mac，可随兼容的数据库副本恢复；应用不主动同步。加密格式和密钥版本必须支持既有密文读取或显式迁移，不能在应用升级时无提示地丢失凭据。

日报草稿、比较基线和会话快照只留内存。切换日期保留各日期草稿；关闭日报窗口或退出前，检查全部日期和时区的草稿，存在草稿时提供“放弃并关闭／返回编辑”（退出采用对应措辞），用户需要保留的内容先明确保存。真正关闭、退出或崩溃后不恢复；隐藏或最小化不算关闭。手写内容和对既有日报的修改遵守同一规则。完整合格生成结果直接成为内存草稿，明确保存失败保留原日报与草稿，不再有待写入草稿恢复数据的生成状态。

同一数据目录只允许一个应用实例使用日报存储，避免首版引入多实例编辑冲突合并。应用不维护自动备份或历史版本档案；只允许原子提交和迁移所必需、完成后清理的事务辅助数据。真正损坏或格式无法解释时保留原数据，停止受影响的操作，不自动重置为空库或静默丢弃记录；正常崩溃事务恢复不属于损坏抢救。

这以本地事务和明确恢复边界换取内容、配置与删除行为的一致性；不提供沙盒隔离、额外正文加密、任意系统备份一致性或磁盘残留擦除的保证。现有模型监控和蓝牙配置不因本决策迁移。

已确认的后续边界：支持的格式升级自动执行事务迁移；已保存工作日报不保留来源材料，草稿结束后不积累比较基线；不持久化生成时间、质量等级、降级原因或生成契约版本，不建立完整生成配置档案。数据库格式版本、AI 配置校验基线等仍按各自用途管理，不属于日报生成档案。

已保存工作日报仍保留报告日（日历日期与实际 IANA 报告时区）、正文、保存时间和最后编辑时间。迁移失败保留原数据；不支持新版格式的旧应用拒绝读写，不自动降级、重置为空库或将未知字段静默替换成默认值。

人工备份与整体替换恢复要求应用完全退出、无实例写入，并保留数据库必需的事务辅助文件；不内置备份或导入界面。正常“清空全部日报内容”保留设置和凭据；损坏时提供的“重置日报功能数据”须另行确认全部范围，清除整个日报数据库，包括设置和凭据，且不暗中留旧库备份。单份凭据无法解密只阻断对应配置，不自动清空它或重置数据库。

完整字段、状态转换、事务、迁移、恢复及前序规则替代范围以[确定日报与非敏感配置的本地持久化契约](https://github.com/PerryFinn/random-thoughts/issues/17)的正式决议为准。本轮仅确认架构与产品契约，不代表生产功能已经实现。
