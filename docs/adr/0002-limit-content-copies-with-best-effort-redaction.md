# 限制正文副本并对会话快照采用尽力脱敏

为减少持久化的正文副本，首版只长期保留用户明确保存的工作日报，不额外保留其来源材料或结构化来源关联；用户自行写入正文的文字、路径和链接仍原样保存。日报草稿、会话快照和草稿基线只存在于本次日报窗口的内存中；切换日期仍可继续编辑，关闭窗口、退出或崩溃后不恢复。草稿基线只用于当前草稿的正文比较，随草稿清除或替换释放，不积累版本历史。不额外保存完整请求、原始响应、分批中间摘要、历史日报上下文正文副本或凭据原值映射。

会话快照在固定前、生成输入在外发前、生成结果在成为草稿前尝试遮盖高置信度凭据；为保持流程可继续，脱敏失败不阻断，既有快照不被重写，需持久化的工作内容仍按敏感工作数据保存在当前用户的应用私有目录，首版不另做正文加密。AI 服务凭据加密存入本地数据库，加密密钥随应用打包，不使用 Keychain；这只防止数据库中凭据明文直接可见，不抵抗获得应用和数据库后的解密，也不提供仅限当前 Mac 的绑定。

这一取舍以不恢复未保存草稿换取更少的持久内容，但不保证清除所有秘密、恢复被遮盖的原值或重现历史生成的全部输入；原有删除、网络及诊断边界见[确定敏感数据、凭据与本地保留边界](https://github.com/PerryFinn/random-thoughts/issues/10)。

本 ADR 的内容保留与凭据存储边界由[确定日报与非敏感配置的本地持久化契约](https://github.com/PerryFinn/random-thoughts/issues/17)修订；该决议替代早期的草稿恢复、来源长期保留和 Keychain 路线，其他隐私规则继续适用。
