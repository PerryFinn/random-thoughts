# 限制正文副本并对会话快照采用尽力脱敏

为支持草稿恢复和固定来源，同时减少持久化的正文副本，首版长期保留工作日报、日报草稿及其关联的会话快照，不额外保存完整请求、原始响应、分批中间摘要、历史日报上下文正文副本或凭据原值映射。

会话快照在固定前、生成输入在外发前、生成结果在成为草稿前尝试遮盖高置信度凭据；为保持流程可继续，脱敏失败不阻断，既有快照不被重写，需持久化的工作内容仍按敏感工作数据保存在当前用户的应用私有目录，首版不另做内容加密，AI 服务凭据则独立保存在仅限当前 Mac 的 Keychain 中。

这一取舍保留用户编辑和日报使用的连续性，但不保证清除所有秘密、恢复被遮盖的原值或重现历史生成的全部输入；完整行为与删除、网络及诊断边界见[确定敏感数据、凭据与本地保留边界](https://github.com/PerryFinn/random-thoughts/issues/10)。
