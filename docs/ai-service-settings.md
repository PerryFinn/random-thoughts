# 三协议配置与 AI 服务凭据

本切片实现 [#27](https://github.com/PerryFinn/random-thoughts/issues/27)，遵守父规格 [#20](https://github.com/PerryFinn/random-thoughts/issues/20) 第 4、5、11、12、13 组和 ADR-0002／0003。起点为本地 `c43f0d2`，其中已包含 #23 的 `27b065e`。GitHub #23 仍开放且被 #22 阻塞，#27 仍被 #23 阻塞；本票不改变远端状态。

## 配置与编辑保护

界面和主要业务测试共用 `DailyReportFlow.send`。Chat Completions、Responses、Messages 各保留唯一隔离配置，当前 AI 服务配置独立且可为空。每次只保留一个类型的未提交编辑；切类型、切页、关闭设置或退出统一提供取消、放弃、保存并继续。退出面板同时列出全部日报草稿。失败保留完整旧值、编辑输入及原页；提交期间冻结编辑与结束动作，旧窗口／编辑代次／确认无效。即使没有未保存输入，离开 AI 页也结束该页的编辑代次并撤销待定确认；往返该页不能让旧删除确认或编辑回调重新生效。

同一编辑代次内，连续输入和切换字段均累积到当前配置，不能因前一次输入而拒绝后续字段回调。保存成功、撤销、切类型或离页后，旧编辑回调才失效；保存失败仍保留本次输入。

端点初始为空，仅 placeholder 提供完整示例。只 trim 两端空白，保留完整路径、query、大小写与尾斜杠；非空地址须为有 host、无 userinfo／fragment 的绝对 HTTP(S) URL。HTTP 显著标为明文。模型手填，不拉清单。允许端点、模型和凭据未填，非空格式／范围错误持续定位字段并阻止保存。

默认值分别存储：Chat Completions 温度 0–2、`reasoning_effort`；Responses 温度 0–2、`reasoning.effort`；两者 effort 为未设置或 none/minimal/low/medium/high/xhigh/max。Messages 温度 0–1，thinking 为端点默认／关闭／adaptive，仅 adaptive 可选 `output_config.effort`（未设置或 low/medium/high/xhigh/max）。未设置与显式 0／none 不合并，不增加跨协议公共生成参数。C／O 为正整数且 C>O，默认 65,536／16,384；并发默认 3、范围 1–8，必要预算字段不得为空。这些控制不属于生成偏好。

保存、校验、设为当前各是独立动作；启动、切类型或保存不联网、不自动选择当前。#28 接入 [Chat Completions 显式探测与直接生成](chat-completions-generation.md)，#29 接入 [Responses 原生校验与生成](responses-generation.md)，#30 接入 [Messages 原生校验与生成](messages-generation.md)。只有完整、凭据可读、已校验且基线匹配的配置才可设为当前；失去资格保留当前身份，不自动换服务。

校验基线明确绑定协议、完整端点、模型、原生默认值、逻辑凭据版本、鉴权／固定版本头、O、OpenAI 的 `store:false`、Responses 的 `truncation:disabled` 和探测契约版本。端点与模型按 UTF-8 原始字节比较，不把 Unicode 规范等价但请求字节不同的标识合并；这同时用于编辑保护和基线匹配。请求字段变化要求重新校验；C／并发不改变基线。恢复时基线不匹配只降低对应资格，不沿用旧能力证据。

## 凭据与事务

专用 Key 使用真实 CryptoKit AES.GCM、随包稳定版本密钥和每次随机 nonce；封装格式／密钥版本及标准 combined 密文。测试注入独立合成密钥。不使用 Keychain、口令或设备绑定；只避免数据库直接出现专用 Key 明文，获得应用与数据库仍可解密。

内存加密成功后，新配置、密文、逻辑凭据版本和校验状态同一 SQLite 事务提交。空新 Key 保留旧密文及逻辑版本；非空替换即使原值相同也更新逻辑版本并失去旧资格。加密／提交失败完整保留旧值与编辑输入，成功才清新输入。

已保存 Key 默认掩码；主动显示／复制才产生可读值。切类型、离页、关闭或配置变化清显示值。新输入与已保存 Key 分开，不把旧明文填回输入；复制只走显式注入的 `copyText` 剪贴板出口，日报 `.copyMarkdown` 与凭据 `.copyAICredential` 仍是独立业务动作。日志不记录 Key／密文／内置密钥／端点／模型或原始 Error。配置保存、当前选择、凭据删除只通过类型化 `report_storage_finished` 入口记录固定操作／结果；schema 和密文格式版本也是固定数值，不输出逻辑凭据版本。

删除凭据单独确认，默认取消。有未保存配置先保存或撤销；确认绑定协议、逻辑版本与编辑代次。删除事务仅清密文、更新逻辑版本和资格，保留全部配置字段及当前身份；失败保留原值。未知密文／密钥版本或认证失败保留原封装，标为无法读取，仅阻断对应配置的测试／生成／显示／复制，允许重填保存或确认删除，其他配置及日报仍可用。

## 持久化与验证

schema 4 在同库增加三协议配置、凭据封装、逻辑版本、校验证据及独立当前选择。缺行、未知协议、坏业务字段／表结构停止读写并保留原库；凭据不可读由对应配置局部处理。[#33](daily-report-storage-management.md) 将受支持旧 schema 事务升级至 5，并将可读格式 1 凭据升级至格式 2；保留旧密钥读取，封装变化不改变逻辑版本。未知新版拒绝读写，不自动重建或重置；只允许用户明确确认的整库重置。

已确认测试边界为流程动作／状态、真实 SQLite／CryptoKit 和无窗口 NSHostingView 布局。仅合成材料与独立目录；启动、保存、切换后传输请求数为零，不启动应用或访问真实 Codex／AI。验证随机 nonce、版本／认证错、加密／提交失败、删除回滚、主动复制及完整日志对象。实际命令、结果与未执行项见 [testing.md](testing.md)。
